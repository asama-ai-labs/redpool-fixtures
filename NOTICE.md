# Data Provenance and Usage Notice

This repository contains curated Redfish API response samples collected from physical server hardware operated in Asama.ai's laboratory.

## Data sources

The datasets include responses collected from server management interfaces across multiple hardware vendors, including Dell, HPE, Lenovo and Supermicro.

The underlying responses are generated by the respective hardware management interfaces and may contain vendor-specific properties and extensions.
